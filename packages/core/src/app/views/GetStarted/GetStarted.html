Get Started

AnywhereUI is a rich set of open source Web Components with bindings for Angular, React and Vue.

Requirements

AnywhereUI targets evergreen browsers and ships as native Web Components. The repository itself is built with Node 26 (see .nvmrc) and npm 11 workspaces; the library packages only require Node 22.22.3 or newer for building.

Install the core package

npm install @anywhere-ui/core
Register the custom elements

With a bundler, load the elements from the Stencil loader:


import { defineCustomElements } from "@anywhere-ui/core/loader";

defineCustomElements();

Or load them straight from a CDN in a plain HTML page:


<script type="module" src="https://unpkg.com/@anywhere-ui/core/dist/anywhere-ui/anywhere-ui.esm.js"></script>
<link rel="stylesheet" href="https://unpkg.com/@anywhere-ui/core/dist/anywhere-ui/anywhere-ui.css" />

Every component is then available as a normal HTML tag:


<any-button label="Submit"></any-button>
<any-checkbox label="Remember me"></any-checkbox>
Angular

npm install @anywhere-ui/core @anywhere-ui/angular
  

import { NgModule } from "@angular/core";
import { AnywhereUiModule } from "@anywhere-ui/angular";

@NgModule({
  imports: [AnywhereUiModule.forRoot()],
})
export class AppModule {}

The module registers the components as Angular components and wires the value accessors, so ngModel and formControl work on the form components: 


<any-button label="Submit" (aOnClick)="submit()"></any-button>
React

npm install @anywhere-ui/core @anywhere-ui/react
  

import { AnyButton, setupAnywhereUIReact } from "@anywhere-ui/react";

// once, in your entry file
setupAnywhereUIReact();

export function App() {
  return <AnyButton label="Submit" onClick={() => console.log("clicked")} />;
}

The React wrappers are generated by @stencil/react-output-target and proxy every any-* element, including its events.

Vue

npm install @anywhere-ui/core @anywhere-ui/vue
  

import { createApp } from "vue";
import { AnywhereUIVue } from "@anywhere-ui/vue";
import App from "./App.vue";

createApp(App).use(AnywhereUIVue).mount("#app");

The Vue proxies support v-model on the form components (any-checkbox, any-input-switch, any-dropdown, any-listbox, any-multiselect, any-radio-button).

Run the showcase locally

The documentation site in this repository is itself built with the components:


git clone git@github.com:adaleks/anywhere-ui.git
cd anywhere-ui
npm install
npm start

npm start runs the Stencil dev server (watch mode, Sass watcher for the showcase styles) on http://127.0.0.1:3333.

Build and test

npm run build        # core + Angular, React and Vue bindings
npm test             # unit tests (Vitest via @stencil/vitest)
npm run test:e2e     # browser tests (Playwright via @stencil/playwright)
